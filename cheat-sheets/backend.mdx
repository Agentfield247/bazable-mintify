## First-time setup

<Steps>
  <Step title="Install the CLI">
    ```bash
    npm install -g bazable-api
    ```
  </Step>
  <Step title="Initialize and extract">
    ```bash
    cd your-backend
    bazable init
    bazable extract --payloads
    ```

    Discovers APIs from your own code and infers request payloads.
  </Step>
  <Step title="Publish the contract">
    ```bash
    bazable push
    ```

    Creates a cloud project on first push and uploads the contract.
  </Step>
</Steps>

## Daily workflow

```bash
bazable diff https://api.example.com/v1/users    # check if live API matches contract
bazable test --all --token <token> --method POST # test all endpoints
bazable push                                     # update contract after changes
```

## When the frontend expects changes

```bash
bazable sync                                     # pull latest contract from cloud
bazable generate backend --framework express     # generate route stubs from contract
```

## Handy options

| Command | Purpose |
| --- | --- |
| `bazable serve` | Spin up a mock server for testing. |
| `bazable ui` | View the contract visually. |
| `bazable import openapi.yaml` | Import an existing OpenAPI spec. |
| `bazable inspect` | Validate backend code against the contract. |
