## 1. Install the CLI

<CodeGroup>

```bash npm
npm install -g bazable
```

```bash pnpm
pnpm add -g bazable
```

```bash yarn
yarn global add bazable
```

</CodeGroup>

Verify the install:

```bash
bazable --version
```

## 2. Initialize a project

From the root of your app, create a `bazable.config.json`:

```bash
bazable init
```

This reads your `package.json` for the project name and seeds an empty endpoints list. See [`bazable init`](/commands/init) for details.

## 3. Extract endpoints from your code

Scan the codebase to auto-populate the contract with real endpoints and payload schemas:

```bash
bazable extract -r
```

Use a preset for non-JS stacks:

```bash
bazable extract -s py    # Python
bazable extract -s go    # Go
bazable extract -s rb    # Ruby
```

Full options in [`bazable extract`](/commands/extract).

## 4. Validate code against the contract

```bash
bazable inspect
```

`inspect` flags dead URLs, payload mismatches, and over-fetching. Run it locally, in a [pre-push hook](/commands/hook), or in [CI](/commands/ci).

## 6. Sync with your team

Push the contract to Bazable Cloud so teammates can pull it:

```bash
bazable push
bazable sync
```

Authenticate the CLI with [device code login](/cloud/device-auth).
