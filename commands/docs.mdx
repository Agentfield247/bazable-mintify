Generates static API documentation HTML from the contract.

## Usage

```bash
bazable docs [options]
```

## Options

<ParamField query="-o, --output" default="./bazable-docs" type="string">
  Output directory for the generated documentation.
</ParamField>

## Example

```bash
bazable docs -o ./public/api-docs
```
