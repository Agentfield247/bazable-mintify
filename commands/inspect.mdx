Validates your code against the contract. Detects dead URLs, payload type mismatches, and over‑fetching.

## Usage

```bash
bazable inspect [options]
```

## Options

<ParamField query="-f, --fix" type="boolean">
  Auto-correct simple type mismatches directly in source files.
</ParamField>

<Note>
  `inspect` also accepts all [`bazable extract`](/commands/extract) options (presets, patterns, extensions, and more).
</Note>

## Examples

<CodeGroup>

```bash Check for violations
bazable inspect
```

```bash Auto-fix mismatches
bazable inspect -f
```

</CodeGroup>

<Tip>
  Enforce contracts automatically with [`bazable hook`](/commands/hook) or [`bazable ci`](/commands/ci).
</Tip>
