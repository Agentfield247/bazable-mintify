Starts a mock API server based on your contract. Smart data generation with realistic values.

## Usage

```bash
bazable serve [options]
```

## Options

<ParamField query="-p, --port" default={4000} type="number">
  Port to listen on.
</ParamField>

<ParamField query="-d, --delay" type="number">
  Simulated network delay in milliseconds.
</ParamField>

## Example

```bash
bazable serve -p 5000 -d 300
```

<Tip>
  Point your frontend at `http://localhost:4000` to develop offline against the contract.
</Tip>
