---

sidebarTitle: "hook"
description: "Install a pre-push Git hook"
---

Installs a pre‑push Git hook that runs `bazable inspect` before every push.

## Usage

```bash
bazable hook
```

## Options

<Info>
  This command takes no options.
</Info>

## Example

```bash
bazable hook
```

<Warning>
  Pre-push hooks live in `.git/hooks/` and are not committed. Every teammate must run `bazable hook` in their own clone.
</Warning>
