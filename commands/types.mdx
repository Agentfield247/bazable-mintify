Generates TypeScript type definitions (`bazable-types.ts`) for every request and response schema in your contract. Use them directly in your frontend or backend for compile-time safety.

## Usage

```bash
bazable types [options]
```

## Options

<ParamField query="-o, --output" default="cwd" type="string">
  Output directory for the generated types file.
</ParamField>

<ParamField query="--stdout" type="boolean">
  Print to the terminal instead of writing a file.
</ParamField>

## Example

```bash
bazable types -o ./src/types
```

<Tip>
  Pair with [`bazable client`](/commands/client) to get typed request functions alongside typed request and response models.
</Tip>
