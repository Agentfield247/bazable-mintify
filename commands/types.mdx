Generates TypeScript interfaces from the stored response schemas in your contract.

## Usage

```bash
bazable types [options]
```

## Options

<ParamField query="-o, --output" default="cwd" type="string">
  Output directory.
</ParamField>

<ParamField query="--stdout" type="boolean">
  Print to the terminal instead of writing a file.
</ParamField>

<ParamField query="--prefix" type="string">
  Prefix for generated interface names.
</ParamField>

<ParamField query="--name" type="string">
  Override the interface name (only for a single schema).
</ParamField>

## Example

```bash
bazable types -o ./src/types
```

<Tip>
  Pair with [`bazable client`](/commands/client) to get typed request functions alongside typed response models.
</Tip>
