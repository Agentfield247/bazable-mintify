Sends real HTTP requests to every contracted endpoint and reports health.

## Usage

```bash
bazable test [options]
```

## Options

<ParamField query="-t, --token" type="string">
  Access token for authenticated endpoints.
</ParamField>

<ParamField query="-e, --email" type="string">
  Auto-login email.
</ParamField>

<ParamField query="-p, --password" type="string">
  Auto-login password.
</ParamField>

<ParamField query="-m, --method" default="GET" type="string">
  HTTP method to use when testing.
</ParamField>

<ParamField query="-w, --write" type="boolean">
  Allow testing of write endpoints (POST, PUT, PATCH, DELETE).
</ParamField>

<ParamField query="-k, --mock" type="boolean">
  Mock mode. Does not send real HTTP requests.
</ParamField>

<ParamField query="-a, --all" type="boolean">
  Test all endpoints regardless of status.
</ParamField>

<ParamField query="-x, --exclude" type="string[]">
  Skip specific endpoints by URL.
</ParamField>

<Warning>
  Use `--write` with care against live APIs. It will send POST, PUT, PATCH, and DELETE requests.
</Warning>

## Examples

<CodeGroup>

```bash Mock-test all
bazable test -k -a
```

```bash Real test with auto-login
bazable test -e admin@example.com -p secret123 -m POST -w
```

</CodeGroup>
