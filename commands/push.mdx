Uploads the local contract to Bazable Cloud. Creates a cloud project on first push.

## Usage

```bash
bazable push
```

## Options

<Info>
  This command takes no options.
</Info>

## Example

```bash
bazable push
```

<Note>
  Requires an authenticated session. See [Device Code Authentication](/cloud/device-auth) if the CLI is not signed in.
</Note>
