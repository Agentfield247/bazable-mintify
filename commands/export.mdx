Exports the contract as an OpenAPI 3.0 specification.

## Usage

```bash
bazable export [options]
```

## Options

<ParamField query="-o, --output" default="./openapi.json" type="string">
  Output file path.
</ParamField>

## Example

```bash
bazable export -o ./api-spec.json
```

<Tip>
  Pair with [`bazable import`](/commands/import) to round-trip contracts to and from OpenAPI.
</Tip>
