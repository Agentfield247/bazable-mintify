Generates backend code from the contract.

## Subcommands

<Card title="backend" icon="server">
  Express.js or Hono router stubs with Zod validation.
</Card>

## Usage

```bash
bazable gen backend [options]
```

## Options

<ParamField query="-f, --framework" type="string">
  Target framework. One of `express` or `hono`.
</ParamField>

<ParamField query="-o, --output" type="string">
  Output directory for generated files.
</ParamField>

<ParamField query="-v, --no-validation" type="boolean">
  Skip Zod validation schemas.
</ParamField>

## Example

```bash
bazable gen backend -f express -o ./api
```

<Tip>
  Pair with [`bazable gen ui`](/commands/generate-ui) to scaffold matching frontend forms from the same contract.
</Tip>
