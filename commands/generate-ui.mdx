Generates a form component from an endpoint's request schema. By default, produces a **zero‑dependency, standalone HTML file** with embedded CSS and JavaScript. You can also use `--ai` to let an LLM generate the UI for any framework.

## Usage

```bash
bazable gen ui <method> <url> [options]
```

## Options

<ParamField query="-o, --output" default="./generated-ui" type="string">
  Output directory for the generated form.
</ParamField>

<ParamField query="--ai" type="boolean">
  Use an LLM to generate the UI.
</ParamField>

<ParamField query="--framework" type="string">
  Target framework when using `--ai` (for example, `react-tailwind`).
</ParamField>

## Examples

<CodeGroup>

```bash Standalone HTML
bazable gen ui POST https://api.example.com/v1/settlements -o ./my-forms
```

```bash React + Tailwind (AI)
bazable gen ui POST https://api.example.com/v1/settlements --ai --framework react-tailwind
```

</CodeGroup>
