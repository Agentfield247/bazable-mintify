Opens a local web dashboard showing all endpoints, their schemas, and testing tools.

## Usage

```bash
bazable ui [options]
```

## Options

<ParamField query="-p, --port" default={3000} type="number">
  Port for the dashboard server.
</ParamField>

## Example

```bash
bazable ui
```
