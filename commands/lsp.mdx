Starts the Bazable Language Server Protocol engine, providing real-time diagnostics and hover tooltips in editors like VS Code, Neovim, and Zed.

## Usage

```bash
bazable lsp
```

## Options

<Info>
  This command takes no options.
</Info>

## How to connect

Configure your editor's LSP client to run `bazable lsp` for JavaScript, TypeScript, and HTML files. The server communicates over standard I/O using JSON-RPC.

## Example

```bash
bazable lsp
```

<Tip>
  For AI coding agents (Cursor, Cline, Claude Code), use [`bazable mcp`](/commands/mcp) and [`bazable gen context`](/commands/generate-context) instead.
</Tip>
