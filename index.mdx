Bazable is a Git-native API contract management CLI. It scans your frontend or backend code, builds an API contract automatically, and enforces it across your team.

## Key features

- **Zero-config API extraction** from any language.
- **Real-time contract enforcement** for dead URLs, payload mismatches, and over-fetching.
- **Cloud sync** with device-code authentication.
- **Mock server, TypeScript client generation, and backend scaffolding** straight from the contract.
- **AI-native.** Plain-English proposals, endpoint explanations, and a built-in MCP server for coding agents.

## How it works

<Steps>
  <Step title="Initialize">
    Run [`bazable init`](/commands/init) in your project to create a `bazable.config.json`.
  </Step>
  <Step title="Extract">
    Run [`bazable extract`](/commands/extract) to scan your code and populate the contract with real endpoints.
  </Step>
  <Step title="Enforce">
    Run [`bazable inspect`](/commands/inspect) locally, in a [pre-push hook](/commands/hook), or in [CI](/commands/ci) to keep code and contract aligned.
  </Step>
  <Step title="Generate">
    Use [`bazable generate`](/commands/generate), [`bazable gen ui`](/commands/generate-ui), and [`bazable serve`](/commands/serve) to scaffold code, forms, and mocks.
  </Step>
</Steps>
